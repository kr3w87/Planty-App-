# Planty V4.5 · Backup & Export

- JSON-Komplettbackup: Pflanzen, Pflegeverlauf, Gesundheitschecks, Fotometadaten, Räume und lokale Lichtmessungen.
- CSV-Export der Pflanzen.
- JSON-Import mit Upsert nach Datensatz-ID.
- Importdaten werden dem aktuell angemeldeten Benutzer zugeordnet.
- Bilddateien selbst werden nicht exportiert; das Backup enthält Fotometadaten und Pfade.
- V4.5 Gesundheitsmonitor und V4.2 Standortanalyse bleiben enthalten.
