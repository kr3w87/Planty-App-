# Planty V3.8 – Pflegeintelligenz aus echten Daten

Planty nutzt jetzt die dauerhaft gespeicherten `plant_care_logs` für personalisierte Pflegeempfehlungen.

## Neu
- Median der tatsächlichen Abstände zwischen Gieß-/Düngevorgängen je Pflanze
- Kombination aus persönlichem Verhalten und hinterlegtem Pflanzenintervall
- saisonale Anpassung bleibt erhalten
- vorhandenes Lichtprofil wird weiter berücksichtigt
- Anzeige von Datenbasis und Datenqualität
- ab wenigen Vorgängen startet die Personalisierung; bei mehr Historie steigt die Gewichtung der echten Daten
- im Pflanzendetail wird die persönliche Empfehlung erklärt

## Wichtig
Bei Pflanzen ohne ausreichende Historie nutzt Planty weiterhin das hinterlegte Pflanzenprofil. Die App erfindet keine persönlichen Werte.
