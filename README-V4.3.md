# Planty V4.3 · Gesundheitsmonitor

V4.3 ergänzt auf Basis von V4.2 einen Gesundheitsmonitor.

- Gesundheitsübersicht auf der Startseite
- Statusverteilung: Gut / Beobachten / Problem
- Erkennung einer Verschlechterung zwischen den letzten Checks
- Liste der Pflanzen mit aktuellem Handlungsbedarf
- Letzte Gesundheitschecks
- Gesundheitsverlauf in der Detailansicht
- V4.2 Standortanalyse bleibt enthalten

Die Anzeige basiert auf gespeicherten Checks und ist keine Diagnose.
