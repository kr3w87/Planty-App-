# Planty V3.6 · Pflanzendetail

V3.6 baut auf V3.5 auf und macht die Pflanzendetailansicht kompakter und übersichtlicher.

## Neu
- kompakter Kopf mit Foto, Art, Standort und Favorit
- Pflegezustand auf einen Blick
- große Schnellaktionen für Gießen, Düngen, Foto und Beobachtung
- Pflegeempfehlung direkt oben
- Tabs: Übersicht, Verlauf, Fotos, Gesundheit
- deutlich weniger vertikales Scrollen innerhalb einer Pflanze
- bestehender Supabase-Login und Pflegeverlauf bleiben erhalten
