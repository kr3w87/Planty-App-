# Planty V4.9.2 – Pflegeaktionen-Fix

- Gieß- und Düngeaktionen zeigen während der Verarbeitung einen Ladezustand und werden zuverlässig wieder freigegeben.
- Pflegeaktionen werden sofort lokal vorgemerkt und die Anzeige aktualisiert sich direkt.
- Wenn Supabase vorübergehend nicht erreichbar ist, bleibt die Aktion auf diesem Gerät in einer Warteschlange und wird später erneut synchronisiert.
- Die Synchronisierung prüft Fehler und verwendet die angemeldete Benutzer-ID.
- V4.9 Pflanze-löschen bleibt enthalten.

Hinweis: Lokal vorgemerkte Aktionen sind auf diesem Browser/Gerät gespeichert, bis die Synchronisierung erfolgreich war.
