# Planty V3.7 · Lichtmesser

Aufbauend auf V3.6.

## Neu
- Lichtmessung pro Pflanze über den Browser-Umgebungslichtsensor, wenn das Gerät/der Browser `AmbientLightSensor` unterstützt.
- Live-Lux-Anzeige.
- Bewertung des gemessenen Standorts gegen den hinterlegten Lichtbedarf der Pflanze.
- Gespeicherte Lichtmessungen pro Pflanze (bis zu 50) lokal im Browser.
- Letzte Messung wird direkt im Pflanzendetail angezeigt.
- Fallback für Geräte ohne Browser-Lichtsensor: manueller Lux-Wert.

## Wichtig
Browser-Lichtsensoren sind je nach Gerät und Browser unterschiedlich verfügbar. Die App behauptet daher nicht, dass jedes Smartphone automatisch messen kann.

## Start
`index.html` im Browser öffnen bzw. über GitHub Pages bereitstellen.
